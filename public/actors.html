characters

You create a character shell — the GM fills in its capabilities (size, max HP, level, ability scores) afterwards. Those fields are refused here, not silently discarded.

items

Only the GM authors items. You see the catalogue; unidentified entries show their category and picture only.

image library

Upload a file, or paste a link. An upload goes straight from your browser to the bucket — it never passes through this server — and the server then reads the first bytes back to check the file really is the image type it claims to be. A pasted link is stored as-is: every player who views it connects directly to that host, which discloses their IP address to it.

spell catalogue

The catalogue is a rules reference, so every member reads it in full — there is no “unidentified” equivalent. What is confidential is which spells a character has prepared, and that lives on the spellbook below.
